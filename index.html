# REST API

С помощью REST API приложения обмениваются данными по протоколу HTTP.

## Аутентификация

Для доступа к защищенным ресурсам используется аутентификация с помощью Bearer Token.

Передавайте токен доступа в заголовке `Authorization` каждого запроса.

```
curl -X GET "https://api.example.com/v1/projects"
-H "Authorization: Bearer <ACCESS_TOKEN>"
-H "Content-Type: application/json"
```
